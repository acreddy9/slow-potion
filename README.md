# Slow Potion
Here lies the website content for the up-and-coming band Slow Potion :-)

## Limitations
In order for GitHub to host this site for free, it must be static (client-side only). Please see the [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits#usage-limits) documentation for other limitations on file size, repo size, deployment frequency, etc.

I chose to build it without any dependencies to avoid complex maintenance and keep it as lean as possible since the content on this site is fairly simple. Just me, vanilla JavaScript, and a dream!
